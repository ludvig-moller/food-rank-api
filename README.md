# Food Rank API
Ett API för att hantera resturanger, maträtter och recensioner. API:et är byggt med Express och använder en SQLite databas.

## Dokumentation
Dokumentationen kan hittas på endpointen `/docs`

## Starta projektet
Projektet kräver en `.env` fil med variablerna från filen `.env.example`

Kör sedan följande kommandon i terminalen för att starta projektet:
```
npm install
npm run dev
```

Detta startar API:et på localhost med porten från `.env` filen

## Tester
För att köra tester kör kommandot `npm test`
